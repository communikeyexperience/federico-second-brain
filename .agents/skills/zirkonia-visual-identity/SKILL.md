# Identità Visiva ZirkonIA

Fonte: `02 Aree/SOP e Procedure/SOP - Identità Visiva ZirkonIA.md` (versione autorevole — questo file è la controparte eseguibile).

## Regola
Da 2026-08-04: ogni deliverable esterno ZirkonIA va brandizzato — logo reale, palette e impaginazione coerenti. Le note interne del vault restano markdown semplice, la veste grafica si applica solo al deliverable finale.

## Logo — asset reali (2026-08-04), non un wordmark ricreato in CSS
Due file ufficiali forniti da Federico, vedi [[Brand Kit ZirkonIA]] in `03 Risorse/Capitale Intellettuale/Brand/`:
- **Icona**: "Z" cristallina su gradiente verde→blu — uso come sigillo/badge/copertina.
- **Wordmark**: "Zirkon" cromato + "IA" blu su nero — uso in intestazioni/firme.

Non ricreare il wordmark come testo stilizzato via CSS: usare sempre i file immagine reali.

## Tipografia
Titoli: sans bold/geometrico di sistema (es. Helvetica Neue Bold) — stesso registro tecnico/cristallino del wordmark, non serif. Corpo: sans regolare. Numeri/date: monospace. Evitare font da CDN esterni nei PDF stampabili.

## Chiusura standard
Ogni documento esterno chiude con il sigillo "Verba volant, data manent." sotto il wordmark ufficiale (immagine, non testo).

## Cronoprogrammi grafici
Per qualunque Gantt/cronosequenza, applicare insieme [[SOP - Schema di Gantt]] (una riga per fase/evento, corsia a destra, milestone puntuali come rombo, tacche leggibili). Verde per le tappe di setup, blu per gli incontri di evoluzione continua.
