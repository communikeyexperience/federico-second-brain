# RAG

Retrieval-Augmented Generation: architettura in cui l'AI recupera prima le informazioni rilevanti dalla base di conoscenza del cliente e poi genera la risposta. Definito nel documento "il cuore tecnico di ZirkonIA" — ⚠️ vedi flag di discrepanza in cima a [[Roadmap Strategica ZirkonIA 2026-2029]]: questo vault usa oggi un'architettura diversa (testo semplice, non RAG).
